当前版本

中文包版本

2026.06.07.5

桌面入口版本

2026.06.07.5

适配 Hermes

0.16.x、0.15.x、0.14.x、0.13.x；未安装 Hermes 时先自动安装官方 Hermes，版本检测失败、超时或旧版 Hermes 使用 legacy 兼容包。官方最新核对到 Hermes Agent v0.16.0。

更新方式

启动前读取 latest.json，有更新时执行同一个安装器，并重新应用界面、快捷指令与分类补丁。

兼容策略

翻译内容文件

包文件 zh-CN
  • agent.json给 Hermes 读取的任务清单、版本判断和安装边界。
  • latest.json当前中文包版本、兼容范围和下载入口。
  • platforms.jsonWindows、macOS、Linux 一键入口与桌面版汉化策略。
  • install.sh自包含安装器：未安装 Hermes 时先装官方 Hermes，再检测版本、校验文件、启用中文、应用启动界面、快捷指令、网关状态和分类补丁、安装更新辅助脚本。
  • Hermes-zh-CN-Setup.exeWindows 新手入口：下载后运行，失败时会停在安装窗口并显示原因。
  • install-windows.cmdWindows 备用入口：调用 PowerShell 安装器，失败时改用备用入口。
  • install.ps1Windows PowerShell 入口：先安装官方 Hermes，再调用中文增强安装器。
  • hermes-macos-installer.zipmacOS 新手入口：解压后打开 install.command。
  • install.commandmacOS 双击入口：调用同一套中文增强安装器。
  • xiaoma-hermes状态查看、更新检查和启动前更新。
  • manifest.json中文包版本、SHA256 和文件清单。
  • zh-cn.min.json中文增强内容、安装动作和 Hermes 技能说明。
